# Data acquisition

The datasets are credited to their Kaggle pages. Do not commit large raw datasets or private credentials to GitHub.

## CRISP-DM — Telco Customer Churn

Download: <https://www.kaggle.com/datasets/blastchar/telco-customer-churn>

Expected file: `CRISP-DM/data/WA_Fn-UseC_-Telco-Customer-Churn.csv`

## KDD — Credit Card Fraud Detection

Download: <https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud>

Expected file: `KDD/data/creditcard.csv`

## SEMMA — Mall Customer Segmentation

Download: <https://www.kaggle.com/datasets/shwetabh123/mall-customers>

Expected file: `SEMMA/data/Mall_Customers.csv`

The Kaggle API can download each dataset after authentication. In Colab, upload the CSV into the matching `data/` folder or mount Google Drive. Never commit `kaggle.json`.
