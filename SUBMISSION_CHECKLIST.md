# Submission checklist

## Required before sharing the GitHub link

- [ ] Repository is public, or the instructor has access.
- [ ] Three projects use three different datasets.
- [ ] Each project has a Colab-ready `.ipynb` and a matching report.
- [ ] Every notebook runs from top to bottom after the dataset is placed in its documented path.
- [ ] Data source and license/usage notes are included.
- [ ] Train/test separation and preprocessing are leakage-safe.
- [ ] Metrics match the problem type: PR-AUC/recall for fraud, ROC-AUC/recall for churn, silhouette/inertia for clustering.
- [ ] Results in the report are regenerated from the final notebook run.
- [ ] Limitations, ethical considerations, and deployment/monitoring are documented.
- [ ] Medium article and walkthrough video links are added when available.
